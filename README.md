# Obsidian Yuque Helper

Manually sync Markdown notes from Obsidian to Yuque, one top-level folder per knowledge base.

以 Obsidian 为准，手动将笔记同步到语雀。勾选一个一级文件夹，对应建立一个私有知识库；笔记中引用的图片一并上传。无需填写 API Token。

当前版本 **0.1.5** 为桌面试用版，要求 Obsidian **1.5.0 或以上**。使用语雀网页登录会话和原生富文本转换接口，已在一个个人账号通过连接自检。其他账号请先运行自检；网页接口及账号的空间、上传限制仍可能影响使用。

## 安装

1. 从 [Releases](https://github.com/ASOAT/obsidian-yuque-helper/releases) 下载 `obsidian-yuque-helper-0.1.5.zip`，解压得到 `notebox-yuque-sync` 文件夹。也可以单独下载 `main.js`、`manifest.json` 和 `styles.css`。
2. 将解压后的文件夹放入笔记库的 `.obsidian/plugins/`；单独下载时则在 `.obsidian/plugins/notebox-yuque-sync/` 中放入这三个文件。文件夹名必须与插件编号一致。
3. 重启 Obsidian，在「设置 → 第三方插件」中启用 **Obsidian Yuque Helper**。

目录应为：

```text
你的笔记库/
└─ .obsidian/plugins/notebox-yuque-sync/
   ├─ main.js
   ├─ manifest.json
   └─ styles.css
```

升级时替换这三个文件，保留原目录中的 `data.json`。

## 第一次使用

1. 打开插件设置，填写「语雀个人路径」：填写你个人主页地址最后一段的标识，而不是昵称。此设置初始为空。
2. 点击「打开登录窗口」，在插件窗口中正常登录自己的语雀账号，再回到 Obsidian 点击「检查登录」。其他浏览器的登录不会自动共享。
3. 点击「运行连接自检」。插件只用虚构内容，检查建库、文档创建与更新、图片上传、发布后读回和删除；测试知识库及展示文档会保留供你检查。自检成功后才开放真实笔记同步。
4. 勾选需要同步的一级文件夹，点击「预览同步 → 开始同步」。以后修改笔记后，仍需手动同步。

也可点击左侧云朵图标，或在命令面板搜索「语雀」。新增的一级文件夹会出现在设置中，默认不会自动勾选。

## 同步规则

- 只同步选中文件夹及其子文件夹中的 `.md` 笔记。根目录笔记、PDF、Canvas 和其他文件不会成为语雀文档；子文件夹笔记归入其一级文件夹对应的知识库。
- 首次同步新建私有知识库和文档，以编号保存配对，不按标题接管已有文档。再次同步沿用配对；语雀中的正文改动会被本地内容覆盖。
- 支持常规 Markdown、代码、数学公式、双链接和引用图片。图片可位于库内未勾选的附件文件夹；未引用的图片不会上传，相同图片内容复用上传地址，网络图片地址保留。
- 笔记间链接转换为语雀文档链接。没有同步或不存在的目标显示可读文字并提示；标题、段落定位转为整篇文档链接，笔记嵌入转为链接，不展开全文。
- 「同步删除」默认开启，只将本插件配对且仍在选中范围内的已删除笔记对应文档移入语雀回收站。取消勾选会保留远端内容，知识库不会自动删除。
- 文件夹缺失、扫描失败、写入失败或同步期间本地内容变化时，会阻止相关删除。跨文件夹移动先完成目标文档，再删除旧文档。

插件不改写本地笔记正文或添加 frontmatter。同一文件夹内的重命名在插件运行时保留文档配对；插件关闭期间的重命名可能产生新文档及新链接。一级文件夹重命名会保留配对，远端知识库名称暂不自动更改。

## 登录与配对记录

「记住登录」默认开启。登录检查确认账号后，插件将独立会话中的临时 Cookie 在本机保留最多 30 天；已有持久 Cookie 保持原过期时间。Cookie 由 Electron 保存在笔记库之外的应用会话存储中，不保存密码，也不读取 Chrome 等其他浏览器的登录凭据。

语雀服务端使登录失效时仍需重新登录。关闭「记住登录」在下次重载插件或重启 Obsidian 时生效，当前会话结束时清除登录。「退出登录」会终止本插件会话并清除其登录状态，保留知识库、文档和配对记录；重新连接后也不会自动同步。

**请备份插件目录中的 `data.json`。** 它保存设置、账号标识、知识库与文档编号、上传地址等配对信息，不含登录 Cookie 或 Token。丢失后插件无法识别已有配对，可能重新建库或建文档。不要将自己的 `data.json` 或登录会话目录提交到公共仓库。

## 当前限制

- 仅支持桌面端、单向和手动同步；不提供语雀到 Obsidian 的反向同步。
- 依赖未公开承诺稳定的网页接口，语雀更新后可能需要适配。连接自检失败时请查看「查看结果」中的错误信息。
- Dataview / DataviewJS 查询保留为代码并提示，语雀不会执行查询；其他 Obsidian 插件专用语法不能保证排版一致。
- 本地 HTML 图片、PDF 与其他附件上传尚不支持；单张图片上限为 20 MB。
- 开头 YAML 元数据和 `%%…%%` 注释不上传。

## 开发

无需安装额外依赖。使用 Node.js 运行：

```text
npm test
npm run check
npm run package
```

`npm test` 先构建，再运行模拟测试；`npm run package` 在 `dist/` 生成安装 ZIP 及可单独下载的插件文件。GitHub Actions 自动运行这些检查。

`main.js` 是构建后的单文件插件，并嵌入本项目及第三方组件的完整许可证通知。静态 HTML 缓存使用内置 Markdown-it 14.1.0，第三方授权见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)；笔记中的代码不会执行，实际富文本使用语雀原生转换结果。本项目采用 [MIT 许可证](LICENSE)。
